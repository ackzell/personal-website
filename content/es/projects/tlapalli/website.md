Un sitio web con un selector especial para temas. Efectos de sonido y vibraciones para dispositivos móviles, cambia entre modos oscuro y claro además de seguir a tu sistema operativo para cada una de las 16 variaciones. Un efecto de vidrio cuidadosamente fabricado en la barra de navegación, así como la responsividad y las scroll transitions en la página.

::

Quería compartir las  diferentes variaciones de una forma más interactiva que no fuera solamente en el README, así que pensé en que podría crear una landing page, algo así como lo que tiene Ayu. Así es que nació este sitio web.
